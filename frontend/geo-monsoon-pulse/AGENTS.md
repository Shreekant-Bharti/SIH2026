# MediChain Frontend — Agent Guidelines

> [!IMPORTANT]
> Keep the `main` branch in a working state at all times.
> Avoid force-pushing, rebasing, or squashing commits that are already pushed,
> as it rewrites shared history for collaborators.

When contributing to this repository:
- Commits pushed to the connected branch should keep the app functional.
- Do not break the build or introduce regressions without a follow-up fix.
